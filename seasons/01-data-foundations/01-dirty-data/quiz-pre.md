# Lesson 1.1: quiz before the lesson

**1. A column of body weights has a few cells with the value 0. What is the most likely explanation?**

- A) Some penguins weigh nothing
- B) The weight was not recorded, and someone typed 0
- C) The scale was set to kilograms

**2. Why can duplicate rows be a problem?**

- A) They make the file harder to open
- B) Some rows count twice, so counts and averages go wrong
- C) They have no effect if the values are correct

**3. A value far away from all the others is called:**

- A) A label
- B) A feature
- C) An outlier
- D) A duplicate

<details>
<summary>Show answers</summary>

1. B. A real penguin can't weigh 0 g. A zero used for "not measured" is a missing value in disguise.
2. B. A copied row is counted twice, which changes counts and averages. In machine learning it can also leak into the test set.
3. C. An outlier is a value far from the rest. It may be an error, or a rare real value.

</details>
